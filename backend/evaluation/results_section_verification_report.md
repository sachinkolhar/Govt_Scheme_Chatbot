# Results Section Verification Report

**Target audited:** `backend/evaluation/results_section_draft.md`

**Scope:** Current draft contents, current evaluation scripts, generated CSV reports, label-audit outputs, source implementation, and project-level experiment documents. The draft and all source artifacts were left unchanged.

## 1. Executive Verdict

The draft is substantively cautious and its current artifact-derived arithmetic is correct. It correctly distinguishes:

- `IndexFlatL2` squared-distance diagnostics from similarity scores.
- Binary acceptance from exact scheme-identity retrieval.
- Source labels from verified ground truth.
- Diagnostic thresholds from validated operating thresholds.
- Narrative historical claims from reproducible results.
- Absence of a valid same-dataset baseline.

No draft claim was found that describes the candidate `name_similarity_score` fields as FAISS similarity. The draft explicitly states that candidate traceability is not semantic correctness and that the FAISS distance field in the candidate report is unavailable.

The main residual issue is not a numerical error in the draft. It is evidence availability: speech, recommendation, conversational, and latency values are correctly marked provisional, unreproducible, or contradicted because their raw observations and metric-generation artifacts are absent. The historical retrieval result is correctly rejected as non-reproducible.

## 2. Verification Status Definitions

| Status           | Meaning                                                                                                                                      |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Verified         | Directly present in a current artifact or reproduced deterministically from a current artifact; any label limitations are separately stated. |
| Provisional      | Reported in project documentation, but the underlying observations, evaluation script, or complete provenance are missing.                   |
| Contradictory    | Conflicting current sources prevent one value or configuration from being accepted as authoritative.                                         |
| Unsupported      | The claim or metric has no adequate current source/calculation path.                                                                         |
| Not reproducible | A source reports the value, but the current artifacts cannot reproduce it as stated.                                                         |
| Pending review   | Traceability exists, but human canonical mapping or semantic correctness has not been approved.                                              |

## 4. Source and Calculation Review

### 4.1 Current L2 Evaluation Versus Earlier Paper Results

The current artifacts and the earlier paper results are different evaluations:

| Property                    | Earlier report                                    | Current artifacts                                                                |
| --------------------------- | ------------------------------------------------- | -------------------------------------------------------------------------------- |
| Query population            | 50                                                | 64, comprising 49 source-positive and 15 source-negative rows                    |
| Index semantics             | Described as similarity/higher-is-better          | `IndexFlatL2`; FAISS returns squared L2 distance, lower is closer                |
| Acceptance direction        | Historical pipeline uses `top_score >= threshold` | Corrected diagnostic uses `top_distance <= threshold`                            |
| Historical confusion matrix | TP=32, TN=9, FP=5, FN=4                           | At threshold 0.60: TP=3, TN=15, FP=0, FN=46 under source labels                  |
| Reproducibility             | Not reproduced from current assets                | Binary diagnostic output is reproducible, but labels remain partially unresolved |

The earlier matrix arithmetic is internally correct for its stated 50-row population. It is not evidence that the current 64-row L2 evaluation achieves those values. The draft handles this discrepancy correctly and does not present 82.0%, 86.5%, 88.9%, or 87.7% as current confirmed performance.

The original `evaluation_pipeline.py`, `backend/config/settings.py`, `backend/search/semantic.py`, and `backend/chat/processor.py` still contain higher-is-better threshold assumptions. The corrected diagnostic script is therefore the only current output among the inspected artifacts that applies the L2 acceptance direction correctly.

### 4.2 Candidate Name Similarity Versus FAISS Distance

The audit candidate file contains:

- `name_similarity_score`
- `token_jaccard_similarity`
- `sequence_similarity`
- `faiss_distance`

The first three are name/string comparison values generated by the label-audit workflow. `faiss_distance` is not available in that report and is represented by the text `unavailable in label_audit.csv`. The draft never treats these name-similarity scores as FAISS similarity. Its discussion of related or similar scheme names is qualitative and correctly states that candidate traceability does not establish correctness.

### 4.3 Ground-Truth Handling

The draft does not treat all 49 positive labels as verified ground truth. It explicitly uses the term source-labeled population, identifies nine exact mappings, and marks 40 mappings as pending review. It also states that the 3-candidate/147-record audit proves traceability only. This is methodologically correct.

The threshold metrics are nevertheless calculated by the diagnostic script against the source `expected_match` labels. Therefore, the draft's wording "Verified diagnostic; provisional labels" is appropriate; the metrics are reproducible as computations, but their interpretation as model performance remains provisional.

### 4.4 Threshold Selection

The draft reports all current diagnostic rows and states that no threshold is validated or optimal. This is correct. The fact that 1.20 has the largest F1 among the listed diagnostic rows is a descriptive property of the output, not a validation result. No held-out validation set, threshold-selection protocol, or independent test set was found.

### 4.5 Baseline Claims

The draft makes no baseline performance claim. It explicitly says that no valid baseline was evaluated on the same current dataset, query population, labels, and metrics. This is correct. The narrative tables comparing FAISS with BM25, Pinecone, Weaviate, speech APIs, or other LLMs do not contain same-dataset executable outputs and cannot be promoted to baseline evidence.

## 5. Missing Evidence Inventory

The following evidence is required to convert the provisional or unsupported values into publishable results:

1. Frozen dataset, query, encoder, and FAISS index manifests with hashes and row alignment.
2. Human adjudication for all 40 unresolved positive labels, including approved slug or removal decision.
3. A corrected exact-retrieval evaluation after label adjudication, plus a validation-based threshold-selection protocol.
4. Speech audio or a manifest, reference transcripts, predicted transcripts, fixed Whisper model/version, and WER/CER/accuracy scripts.
5. Recommendation profiles, returned rankings, eligibility/relevance judgments, and scripts for F1, NDCG@5, MRR, and MAP.
6. Conversation rating records, evaluator type, rating scale, rubric, and aggregation script for the 155-rating claim.
7. Request-level latency logs, load-generation script, hardware/network conditions, timeout definition, and percentile calculation resolving the 1,073/1,230 ms P95 conflict and the 1,392/1,593 ms P99 conflict.
8. A same-dataset baseline implementation and output using the same labels and metrics.
9. A reproducibility procedure that preserves squared-L2 semantics and distinguishes distance from similarity.
